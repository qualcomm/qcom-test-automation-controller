# Getting started

Thank you for downloading the QTAC Software Suite. Let us learn more about
each of the softwares/tools provided by QTAC.

Here is the summary of the different tools that were installed:

- QTAC Scope: Helps you to perform dynamic power measurements on the debug board
- QTAC Viewer: Helps you to analyse, zoom in/out and export the static data using EPM
- Bug Writer: Application to create bug reports
- EEPROM Utility: Utility for fixing and debugging the QTAC debug board
- Embedded Power Measurement: Helps you to collect static power measurement data from the debug board
- EPM Configuration Editor: Editor for creating the EPM configuration power files
- External Power Control: Command line utility, written in C++ for illustrating automation
- EPM Dump: Command line utility for dumping visible EPM devices
- SCL Dump: Dumps the contents of SCL files produced by the EPM library
- Test Automation Controller: Helps you perform various operations on the target using the debug board
- TAC Configuration Editor: Generate the configuration dynamically for QTAC TAC UI

If you run into any issues, please [open a GitHub issue](https://github.com/qualcomm/qcom-test-automation-controller/issues/new) or use the Bug Writer tool to generate a bug report.
